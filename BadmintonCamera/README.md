# BadmintonCamera

Camera app for iPhone to capture and stream badminton match video.

## Features

- Real-time camera capture at 1080p/60fps
- Video streaming to processing device via Multipeer Connectivity
- Simple camera controls
- Connection status display

## Requirements

- iOS 16.0+
- Physical iPhone device (camera required)

## Setup

1. Open `BadmintonCamera.xcodeproj` in Xcode
2. Select your iPhone as the deployment target
3. Build and run

## Usage

1. Grant camera permission when prompted
2. Wait for connection from processing device (iPad/Mac)
3. Position iPhone to capture full badminton court
4. Start streaming and begin match!
